# 铝产业全产业链数据看板

单文件 HTML 看板，覆盖 L1 铝土矿 → L5 铝加工全产业链。

## 数据
- 铝产业链数据.xlsx (44 sheet) · 近 5 年 (2021-10 → 当前)
- 41 个有效 sheet，月度/日度/分省/进口/库存/成本利润等

## 功能
- **9 个 Tab**：概览 / L1-L8 产业链层级
- **44 张图表**：年度对比 + 同比叠加（左右双轴单图）
- **2026 数据加粗红色高亮**，#N/A 自动忽略
- **投资决策面板**（顶部）：
  - ⚡ 电解铝策略：原料/成本/供给/需求/库存 5 步，权重按数据异常度动态调整
  - 🧪 氧化铝策略：原料/成本/供给/进出口 4 步
  - 策略观点由 bull/bear 评分自动生成
- **短期 / 长期结论**（概览速览表 + 各品种详情卡）：
  - 短期 = 30 天动量（分位动量 + 绝对变化/MAD 兜底）
  - 长期 = 365 天趋势 + 5 年历史分位
  - 结论倾向：偏多 / 偏空 / 中性，附主导因子拆解
- **🔍 形态匹配 9 维矩阵**（概览）：当前 vs 去年同期 vs 前年同期 + 同比 + 趋势标签
- **🧩 4 层思维导图**（各品种）：品种 → 环节 → 数据点 → 本期值 + 数据日期
- **📐 行业数据分位表**（各品种）：当前值 / 5 年均值 / 5 年区间 / 同比 / 历史分位
- **⚖️ 多空权重 6 维条形图**（各品种）：分位 60% + 同比 40%，多头红 / 空头绿
- **目录侧边栏**（左下 📑）：所有 Tab + 思维导图快速跳转
- **数据框架思维导图** (`../data-framework/思维导图.html`)：12 层 · 274 项 · 颜色标注 Excel 覆盖情况

## 数据抽取
`extract_data.js` 自动识别表头行与多区块结构（不硬编码行号）：

- 按表头非空连续区间切块，每块独立定位日期列
- 兼容「指标名称 / 日期」两种表头、跨区块拼接（SMM + Wind）
- 归一化小数存储的开工率（×100）、补齐缺失单位
- 5 年窗口（2021-10 → 当前），无数据 sheet 标记为 empty

## 本地运行

```bash
# 看板已嵌入 echarts + data.json，单文件可直接打开
# 但 file:// 协议下 fetch 思维导图会失败，建议用本仓库 server：
cd ..
node start-server.js
# 访问 http://localhost:8765/
```
