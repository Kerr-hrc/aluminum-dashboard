- **投资决策面板**（顶部）：

  - 🧪 氧化铝策略：原料/成本/供给/进出口 4 步
  - 策略观点由 bull/bear 评分自动生成

## 供需结论体系（结论全部由供给需求推导）

三档周期：**短期 = 1 周 · 中期 = 1-3 月 · 长期 = 年度**

| 档位 | 比较窗口 | 打分口径 |
|------|----------|----------|
| 短期 1 周 | 近 7 天 | 动量分（百分比变化 → |Δ|/2×MAD 兜底） |
| 中期 1-3 月 | 近 60 天 | 动量分 |
| 长期 年度 | 近 365 天 | 5 年历史分位 60% + 趋势分 40% |

**供需缺口 = 需求分 + 供给分**（两者正分均代表利多，故相加而非相减）

- 供给类信号（产量/产能/开工率/净进口/库存/成本）`bearHigh=true` → 数值上升 = 偏空
- 需求类信号（消费量/出口/实际消费）`bearHigh=false` → 数值上升 = 偏多
- **最终分 = 0.60×缺口 + 0.25×(库存分+价格分)/2 + 0.15×利润分**

**显式平衡表**（Excel 中真实存在的两套，优先于代理口径）：
- `L2氧化铝平衡-月`：过剩量 = 产量 + 净进口 − 实际消费量（正 = 过剩/累库，偏空）
- `L3电解铝平衡-月`：去库量 = 实际消费量 − 表观消费量（正 = 去库，偏多），另含月度库存、库存/消费天数

### 关键技术处理
- **月频信号拉长比较期**：月频序列在 1 周档内无新值，强制比较会把「同月同一期」当变化 → 自动拉长至 60 天并标注「月频」，且在短/中档只作 20% 背景权重（快频日/周占 80%）
- **假期扰动抑制**：量能类信号 |Δ| > 2.5×MAD（中期 4.0×MAD）判为假期/统计扰动不计分，不作用于长期档
- **百分比可靠性**：基数须为正、|基数| ≥ MAD/3、近 250 期无正负号翻转，否则改用「绝对变化 / MAD」兜底
- **多空依据方向一致**：论据行按该维度的实际打分方向选取，杜绝「需求 ↓ 却说刚需有支撑」这类自相矛盾
- **长期档补分位**：长期打分主因是 5 年分位，叙述同时给出分位，避免与趋势方向冲突

## 4 阶段决策卡片（§7.2）

每个品种一张卡，四个阶段：

1. **① 输入信号** — 供给/需求/库存/价格/利润 五维原始数据，三档变化并列（含「7天/60天/365天变化」实际跨度标注与月频标记）
2. **② 关键判断** — 6 维（供给/需求/库存/价格/利润/供需缺口）× 三档打分（−1 ~ +1，正 = 偏多）
3. **③ 推理链条** — 供需推测正文（三档）+ 多空博弈（多头依据 / 空头依据，按方向自动分流）+ 供需缺口 chips
4. **④ 结论** — 三档结论卡（倾向 / 综合分 / 缺口分 / 印证-背离标记 / 支撑与压制因子）

## 数据抽取
`extract_data.js` 自动识别表头行与多区块结构（不硬编码行号）：

- 按表头非空连续区间切块，每块独立定位日期列
- 兼容「指标名称 / 日期」两种表头、跨区块拼接（SMM + Wind）
- 归一化小数存储的开工率（×100）、补齐缺失单位
- 5 年窗口（2021-10 → 当前），无数据 sheet 标记为 empty
