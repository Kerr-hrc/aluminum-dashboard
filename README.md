## 供需结论体系（结论全部由供给需求推导）

三档周期：**短期 = 1 周 · 中期 = 1-3 月 · 长期 = 年度**

| 档位 | 比较窗口 | 打分口径 |
|------|----------|----------|
| 短期 1 周 | 近 7 天 | 动量分（百分比变化 → |Δ|/2×MAD 兜底） |
| 中期 1-3 月 | 近 60 天 | 动量分 |
| 长期 年度 | 近 365 天 | 5 年历史分位 60% + 趋势分 40% |

**供需缺口 = 需求分 + 供给分**（两者正分均代表利多，故相加而非相减）

- 供给类信号（产量/产能/开工率/净进口/库存/成本）`bearHigh=true` → 数值上升 = 偏空
- 需求类信号（消费量/出口/实际消费）`bearHigh=false` → 数值上升 = 偏多
- **最终分 = 0.45×缺口 + 0.35×(库存分+价格分)/2 + 0.20×利润分**

### 结论三件套

每档结论除倾向与综合分外，还输出：

1. **形态标签** — `上行 / 下行 / 震荡 / 偏强震荡 / 偏弱震荡`
   - 「震荡」判据：库存与价格方向相反（现货与基本面背离），或供需缺口与库存符号相反（两个口径背离）
   - 同向印证时判为 `上行 / 下行`
2. **展望一句话** — 取该档绝对分最大的信号作主因，标注支撑/压制，附次要因素
3. **风险因素块** — 每条绑定一个**可观测触发值**（如「跌破近 1 年低点」「连续 6 周累库」），当前值与触发线距离同屏显示

### 显式平衡表（Excel 中真实存在的两套，优先于代理口径）
- `L2氧化铝平衡-月`：过剩量 = 产量 + 净进口 − 实际消费量（正 = 过剩/累库，偏空）
- `L3电解铝平衡-月`：去库量 = 实际消费量 − 表观消费量（正 = 去库，偏多），另含月度库存、库存/消费天数

### 关键技术处理
- **月频信号拉长比较期**：月频序列在 1 周档内无新值，强制比较会把「同月同一期」当变化 → 自动拉长至 60 天并标注「月频」，且在短/中档只作 20% 背景权重（快频日/周占 80%）
- **法定长假窗口剔除**：量能类信号（铝棒出库、进口、开工率等）在长假当周普遍失真 → 内置 2021-12 ~ 2026-12 法定长假表，假期周的读数直接剔除，不依赖 MAD 阈值（2026 国庆 10/01~10/07 的铝棒出库 2.55 万吨已被排除，且在输入信号表中标出）
- **MAD 异常抑制**：量能类信号 |Δ| > 2.5×MAD（中期 4.0×MAD）判为假期/统计扰动不计分，不作用于长期档
- **社库月末快照剔除**：`L3 电解铝社会库存` 序列中每个自然月最后一天的点，与 `L3电解铝平衡-月` 的「月度库存」完全相同（逐月核对命中率 100%），是月频快照的重复发布 → 自动剔除，避免制造虚假跳变
- **百分比可靠性**：基数须为正、|基数| ≥ MAD/3、近 250 期无正负号翻转，否则改用「绝对变化 / MAD」兜底
- **多空依据方向一致**：论据行按该维度的实际打分方向选取，杜绝「需求 ↓ 却说刚需有支撑」这类自相矛盾
- **长期档补分位**：长期打分主因是 5 年分位，叙述同时给出分位，避免与趋势方向冲突
- **数据源 + 日期 + 时距标注**：每个信号行、每个结论行都标注来源与数据日期（滞后天数的计算与展示已按用户要求 #4 彻底删除）

## L6 终端需求（年度预测矩阵 + 行业拆分 + 需求推导）

L6 是「年份为列」的年度矩阵（2015-2030），与其他 sheet 的「日期为行」结构不同，走独立的 `extractYearMatrix` 解析器。

### 解析（提取器）
- **解析**：左侧主面板按「年份表头行」切段，每段逐年取值
- **⚠ 比率行识别**：Excel 单元格格式含 `%` → 存的是**小数** → 提取时 ×100 → data.json 存**百分数点**（0.7125 = 0.7125%）。→ **公式里要用回小数必须 ×0.01**；展示时直接加 `%` 号、**不再 ×100**
  - 实测：翻新率 Excel=0.007125 → data.json=0.7125；铝箱率 Excel=0.1 → data.json=10
- **⚠ 行键与列名必须共用 `metricKey()`**：否则 panel 为空时两者不一致 → 按列名取值全落空（实测 **140 列 / 543 单元格丢失**）
- **⚠ 同名指标加 `_n` 后缀**：否则同 sheet 内同名指标互相覆盖（实测 **57 处**）
- **⚠ 段级单位识别**：段首格若匹配 `/^(.*?)\s*(kt|万吨|千吨|吨)$/i` → 前半作段名、后半作该段单位（`L7全球需求` 的 `Global kt` 是千吨，不是万吨）
- **⚠ `L6光伏` 三情景**：第 1 列是情景名（谨慎/中性/乐观）→ 段名合成 `国内光伏用铝需求·谨慎` 等，否则三行互相覆盖只剩「谨慎」

### 平衡恒等式（逐列核对，误差 0）
- 全球平衡 = 中国实际平衡 + 海外实际平衡
- 中国实际平衡 = 中国供需平衡 − 净出口(含铝材)
- 海外实际平衡 = 海外供需平衡 + 向中国净进口(含铝材)

### L6 专属模块（2026-10-21 用户要求 #9）
| 板块 | 内容 |
|------|------|
| 📐 年度供需平衡表 | 全球/中国/海外三口径 |
| 🏭 行业拆分 | 7 大行业（建筑/交运/电力/包装/机械/耐用品/其他）+ 新能源细分（新能源车/光伏/风电/储能/数据中心）各一张年度柱 + YOY |
| 🥧 下游行业占比 | 2025 / 2026 两年饼图，7 大行业占「国内总需求(不含进出口)」 |
| 🔬 行业需求推导 | 逐行业 **驱动因子表**（因子 × 年份 × 单位）+ **需求增量瀑布图** |

**推导链全部引用 Excel 原值**，不编数字。`verify_l6_chain.js` 断言 **59 条恒等式**（7 行业合计 = 国内总需求；各行业主列 = 总表对应列；建筑门窗+模板 = 总计；光伏三情景自洽等）。

**瀑布图 = 逐步替换法（sequential substitution）贡献度分解**：
```
contrib_i = f(x₁..x_{i-1} 当年, x_i 当年, x_{i+1}.. 基年)
          − f(x₁..x_{i-1} 当年, x_i 基年, x_{i+1}.. 基年)
```
望远镜求和 ⇒ **Σcontrib ≡ f(全当年) − f(全基年)**，可逐行复算。乘法链走逐步替换法，加法链递归拆到 Excel 输出行 Δ 作叶子。ECharts 无原生瀑布图 → 「占位柱（transparent）+ 实值柱」双 series 同 stack。

⚠️ 「其他」业的基础值是 **Excel 人工假设值**（220/200/200/170/153 等整齐整数）→ 瀑布图标注「基础值（Excel 假设）」。
⚠️ 包装/机械/耐用品只有总量列（无因子链）→ 只出年度柱 + YOY，**不出瀑布图**。

## 4 阶段决策卡片（§7.2）

每个品种一张卡，四个阶段：

1. **① 输入信号** — 供给/需求/库存/价格/利润 五维原始数据，三档变化并列（含「7天/60天/365天变化」实际跨度标注与月频标记）+ 数据日期 + 来源/滞后
2. **② 关键判断** — 6 维（供给/需求/库存/价格/利润/供需缺口）× 三档打分（−1 ~ +1，正 = 偏多）
3. **③ 推理链条** — 供需推测正文（三档）+ 多空博弈（多头依据 / 空头依据，按方向自动分流）+ 供需缺口 chips
4. **④ 结论** — 三档结论卡（倾向 / 形态标签 / 综合分 / 缺口分 / 印证-背离标记 / 展望 / 风险因素 / 支撑与压制因子）

## 数据抽取
`extract_data.js` 自动识别表头行与多区块结构（不硬编码行号）：

- 按表头非空连续区间切块，每块独立定位日期列
- 兼容「指标名称 / 日期」两种表头、跨区块拼接（SMM + Wind）
- **年度矩阵独立解析器** `extractYearMatrix`（年份为列、无日期列）
- **缺失值语义**：缺失 = **key 完全不存在**，与 0 值天然可区分 → 图表断线不连
- **CIF 零值定点过滤**：`ZERO_AS_MISSING` 白名单只针对 3 个「进口铝土矿 CIF」列（印尼 CIF 仅周五有数，周一~周四的 0 是周报占位）→ **绝不做全局 0 过滤**（`L3洋山铝溢价-日` 的 3870 个 0 是「无溢价」有效值）
- **单位修正**：`UNIT_FIX` / `UNIT_CONVERT` 的 key 必须跟 sheet 名一致（`L7电解铝产量全球-月`），否则量级错 10 倍
- 5 年窗口（2021-10 → 当前），无数据 sheet 标记为 empty
