| 📈 同比 | 最新期 vs 去年同期，**数值 + 百分比**，涨红跌绿 |
| 🔄 环比 | 最新期 vs 上一期，**数值 + 百分比**，涨红跌绿 |
| 🗓 频率 | 日/周/月/季/年 + 观测期数 |

**时间标注的频率感知**（2026-10-20 修正）：只有**日频**谈「滞后」有意义（每日都有新数据，落后即数据源停更）；周/月/季/年频在周期内说滞后无意义，改标「月频 · 距上一期 N 天」等。数据截止日在未来则为**预测值**，标紫色「预测 (领先 N 天)」。

**线型规则**：历年用细线 + 50% 透明，**2026 年为 3px 加粗红线**（`#dc2626`），`z: 10` 置顶。

## 供需结论体系（结论全部由供给需求推导）

三档周期：**短期 = 1 周 · 中期 = 1-3 月 · 长期 = 年度**

| 档位 | 比较窗口 | 打分口径 |
|------|----------|----------|
| 短期 1 周 | 近 7 天 | 动量分（百分比变化 → |Δ|/2×MAD 兜底） |
| 中期 1-3 月 | 近 60 天 | 动量分 |
| 长期 年度 | 近 365 天 | 5 年历史分位 60% + 趋势分 40% |

**供需缺口 = 需求分 + 供给分**（两者正分均代表利多，故相加而非相减）

- 供给类信号（产量/产能/开工率/净进口/库存/成本）`bearHigh=true` → 数值上升 = 偏空
- 需求类信号（消费量/出口/实际消费）`bearHigh=false` → 数值上升 = 偏多
- **最终分 = 0.45×缺口 + 0.35×(库存分+价格分)/2 + 0.20×利润分**

### 结论三件套

每档结论除倾向与综合分外，还输出：

1. **形态标签** — `上行 / 下行 / 震荡 / 偏强震荡 / 偏弱震荡`
   - 「震荡」判据：库存与价格方向相反（现货与基本面背离），或供需缺口与库存符号相反（两个口径背离）
   - 同向印证时判为 `上行 / 下行`
2. **展望一句话** — 取该档绝对分最大的信号作主因，标注支撑/压制，附次要因素
3. **风险因素块** — 每条绑定一个**可观测触发值**（如「跌破近 1 年低点」「连续 6 周累库」），当前值与触发线距离同屏显示

### 显式平衡表（Excel 中真实存在的两套，优先于代理口径）
- `L2氧化铝平衡-月`：过剩量 = 产量 + 净进口 − 实际消费量（正 = 过剩/累库，偏空）
- `L3电解铝平衡-月`：去库量 = 实际消费量 − 表观消费量（正 = 去库，偏多），另含月度库存、库存/消费天数

### 关键技术处理
- **月频信号拉长比较期**：月频序列在 1 周档内无新值，强制比较会把「同月同一期」当变化 → 自动拉长至 60 天并标注「月频」，且在短/中档只作 20% 背景权重（快频日/周占 80%）
- **法定长假窗口剔除**：量能类信号（铝棒出库、进口、开工率等）在长假当周普遍失真 → 内置 2021-12 ~ 2026-12 法定长假表，假期周的读数直接剔除，不依赖 MAD 阈值（2026 国庆 10/01~10/07 的铝棒出库 2.55 万吨已被排除，且在输入信号表中标出）
- **MAD 异常抑制**：量能类信号 |Δ| > 2.5×MAD（中期 4.0×MAD）判为假期/统计扰动不计分，不作用于长期档
- **社库月末快照剔除**：`L3 电解铝社会库存` 序列中每个自然月最后一天的点，与 `L3电解铝平衡-月` 的「月度库存」完全相同（逐月核对命中率 100%），是月频快照的重复发布 → 自动剔除，避免制造虚假跳变
- **百分比可靠性**：基数须为正、|基数| ≥ MAD/3、近 250 期无正负号翻转，否则改用「绝对变化 / MAD」兜底
- **多空依据方向一致**：论据行按该维度的实际打分方向选取，杜绝「需求 ↓ 却说刚需有支撑」这类自相矛盾
- **长期档补分位**：长期打分主因是 5 年分位，叙述同时给出分位，避免与趋势方向冲突
- **数据源 + 日期 + 滞后天数**：每个信号行、每个结论行都标注来源、数据日期与滞后天数（≤3 天绿 / ≤10 天橙 / ≤30 天深橙 / 更久红）

### 口径修正（与 Excel 字段名不一致处）
- `L3铝库存天数变化` 的「中国电解铝库存天数变化：总库存(万吨)」实为**总库存**而非天数 → 看板改标为「总库存(非社库口径)」，并注明与 SMM 社库差 1~4 万吨、不可与平衡表「库存/消费(天)」混淆
- 新增 `SHFE 仓单` 单列（交易所注册交割品，与社会库存口径不同，**不可相加**）
- **千吨 → 万吨统一折算**：`L3电解铝产量全球-月`、`L7全球氧化铝产量-月` 存储口径为千吨但列名标万吨 → 折算系数 ÷10。三重交叉核对确认（中国估算 3874 千吨 = SMM 387.4 万吨；合计 6172 ÷ 31 = 表内日均产量 199.1；中国占比 62.77% 与表内完全一致）
- **拆分混量纲图表**：`L2-price`（元/吨 + 美元/吨）、`L3-trade`（吨 + 万吨）、`L3-prod-global-reg`（万吨 + 万吨/日）各自独立成图
- **铝加工 → 铝合金** 统一改名（Excel 中的 sheet 名 `L5铝加工开工率-周/-月` 保持原样，仅看板显示层改名）
- **沪伦比不含汇率**：反解验证 `沪伦比/(A00÷M3)` 均值 0.9993、标准差 0.011 → 该序列 = LME÷SHFE（未乘汇率），与国际通行口径差约 16%。引用必须注明
- **全球分地区缺欧洲**：「西欧」「中东欧」两列全空，2026-08「合计−中国」=229.8 万吨 vs 分地区求和 165.5 万吨，差额 64.3 万吨即未拆分的欧洲 → 分地区求和不可当作中国以外总量
- **海外减产归因**：中东 52.1→29.9 万吨/月（2026-08 vs 2025-08）× 12 = **-266.4 万吨/年**，占全球年化产量 3.60%；剔除中东后其余地区同比 **+0.40%** → 海外减产几乎全部来自中东，非全球性减产

## L6 终端需求（年度预测矩阵）

L6 是「年份为列」的年度矩阵（162 行 × 60 列），与其他 sheet 的「日期为行」结构不同，走独立的 `extractYearMatrix` 解析器。

- **解析**：左侧主面板（列 0-19）按「年份表头行」切段，每段逐年取值；右侧区域是同一批数据的冗余副本，不解析
- **比率行识别**：`结构%` / `增速%` 段内的行以小数存储（|值| ≤ 2），自动按 % 处理并 ×100；夹在其中的「需求增量」等万吨行按绝对量处理
- **年份标注**：当前年及以后为预测值（表头黄底/灰底），往年为实际值并标注滞后天数
- **平衡恒等式**（逐列核对，误差 0）：
  - 全球平衡 = 中国实际平衡 + 海外实际平衡
  - 中国实际平衡 = 中国供需平衡 − 净出口(含铝材)
  - 海外实际平衡 = 海外供需平衡 + 向中国净进口(含铝材)
- **年度结论卡**（L6 专用，不适用 1 周/1-3 月动量引擎）：全球/中国/海外三口径平衡状态（短缺/过剩/平衡 + 收窄/扩大方向）+ 中国需求结构（建筑 vs 新能源车/光伏同比 + 新能源占比）+ 展望 + 4 条绑定触发值的风险因素
- **预测校验**：用 L3 的 SMM 月度实际产量做交叉校验 —— 已公布月份加总年化 vs L6 年度预测
  - 2026 年：SMM 1-9 月累计 3394 万吨，年化 4525 万吨，L6 预测 4550 万吨，偏离 −0.5%

## 4 阶段决策卡片（§7.2）

每个品种一张卡，四个阶段：

1. **① 输入信号** — 供给/需求/库存/价格/利润 五维原始数据，三档变化并列（含「7天/60天/365天变化」实际跨度标注与月频标记）+ 数据日期 + 来源/滞后
2. **② 关键判断** — 6 维（供给/需求/库存/价格/利润/供需缺口）× 三档打分（−1 ~ +1，正 = 偏多）
3. **③ 推理链条** — 供需推测正文（三档）+ 多空博弈（多头依据 / 空头依据，按方向自动分流）+ 供需缺口 chips
4. **④ 结论** — 三档结论卡（倾向 / 形态标签 / 综合分 / 缺口分 / 印证-背离标记 / 展望 / 风险因素 / 支撑与压制因子）
